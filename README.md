# Movie Rating One-vs-Rest Classification

## Files
- `movie_rating_ovr_dataset.csv`: Generated dataset
- `movie_ovr_training.py`: Standalone training and evaluation script
- `app.py`: Streamlit application
- `requirements.txt`: Required Python packages

## Install dependencies
```bash
pip install -r requirements.txt
```

## Run the training script
```bash
python movie_ovr_training.py
```

## Run Streamlit
```bash
streamlit run app.py
```

Keep all files in the same folder.
